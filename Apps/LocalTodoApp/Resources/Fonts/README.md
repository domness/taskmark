# Bundled Theme Fonts

Unmodified variable TrueType fonts from Google Fonts, pinned to commit
`e44c4b011a820c2cbe2fd2cfa8052037d7edb571`:

- `Inter.ttf`: `ofl/inter/Inter[opsz,wght].ttf`
- `Inter-Italic.ttf`: `ofl/inter/Inter-Italic[opsz,wght].ttf`
- `Figtree.ttf`: `ofl/figtree/Figtree[wght].ttf`
- `Figtree-Italic.ttf`: `ofl/figtree/Figtree-Italic[wght].ttf`

Source: https://github.com/google/fonts/tree/e44c4b011a820c2cbe2fd2cfa8052037d7edb571/ofl

Each family includes its original copyright notice and SIL Open Font License
in the adjacent `Inter-OFL.txt` or `Figtree-OFL.txt`. Filenames are simplified;
font contents and internal names are unchanged. Upright and italic variable
files supply the weights used by native text and Markdown emphasis.

Xcode copies this directory intact. `ATSApplicationFontsPath` registers these
fonts for the app process only; no system installation or download is needed.
